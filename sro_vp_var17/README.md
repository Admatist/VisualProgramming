# СРО №1 — Employee Management System (Вариант 17)

Настольное приложение для управления данными сотрудников, разработанное в рамках самостоятельной работы по дисциплине «Визуальное программирование».

## Технологический стек
* **Язык:** Java 21
* **Интерфейс:** JavaFX, FXML, Scene Builder
* **Сборка и зависимости:** Apache Maven

## Функциональные возможности
* **Табличное представление:** Отображение списка сотрудников с колонками: ФИО, отдел, должность и стаж работы.
* **Интерактивный поиск:** Фильтрация записей в таблице в режиме реального времени по всем полям.
* **Управление записями (CRUD):**
    * Добавление новых сотрудников через модальное окно.
    * Редактирование существующих записей.
    * Удаление выбранных элементов из таблицы.
* **Валидация данных:** Проверка корректности ввода с выводом информативных диалоговых окон (`Alert`) при ошибках.

## Структура проекта
* `src/main/java/com/example/sro1vp17varabdkprv/` — исходный код (модели, контроллеры, главный класс).
* `src/main/resources/com/example/sro1vp17varabdkprv/` — FXML-разметка пользовательского интерфейса.
* `docs/` — отчёт по СРО и презентация в формате PDF.

## Инструкция по запуску
1. Убедитесь, что у вас установлены **JDK 21** и **Apache Maven**.
2. Откройте терминал в папке проекта `sro_vp_var17`.
3. Запустите приложение с помощью Maven-плагина JavaFX:
   ```bash
   mvn javafx:run
